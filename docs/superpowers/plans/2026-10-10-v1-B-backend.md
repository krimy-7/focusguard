# FocusGuard v1 · Stream B · Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the hackathon backend with the v1 backend: four Alembic-managed data tables (plus a `deleted_users` tombstone), Supabase JWT auth, and the exact REST contract C1 (`/me`, `/goals`, `/contexts`, `/daily`), every query scoped to the token's user.

**Architecture:** FastAPI + SQLAlchemy 2 with a single `app/` package: `config.py` (env), `database.py` (engine/session), `days.py` (clock + local-day math), `models.py` (4 data tables + `deleted_users`), `schemas.py` (all request/response models and validation), `auth.py` (JWT → user id → profile, rate limit), and one router per resource. The schema is created only by Alembic (`migrations/versions/0001_initial.py`), portable across SQLite (dev/tests) and Postgres (prod). Tests use a locally generated ES256 key served through a patched JWKS fetch, so they never touch the network.

**Tech Stack:** Python 3.10, FastAPI 0.115.12, SQLAlchemy 2.0.40, Alembic 1.15.2, Pydantic 2.11.4 / pydantic-settings 2.9.1, PyJWT[crypto] 2.10.1, httpx 0.28.1, tzdata 2025.2, psycopg 3.2.6, pytest 8.3.5. (Container + Cloud Run deploy are Phase 5, spec §10: not in this plan.)

**Spec:** `docs/specs/2026-10-10-v1-core-design.md` (§3, §6, §7) · contract C1 in `docs/superpowers/plans/2026-10-10-v1-core-index.md` · auth details in `docs/research/2026-10-10-auth-hosting.md` §3.

## Global Constraints

- Executors **never run git**. Every "Report to lead" step = list of files changed + the pytest output.
- Edit only `backend/**`. Need a change elsewhere (e.g. `start.bat`, `scripts/dev.ps1`, `README.md`) → write it in your report.
- Python **3.10** (`py -3.10`). Use `X | None`, not `Optional`; no 3.11+ features (no `datetime.UTC`, no `tomllib`).
- All commands run from `backend/` with the venv interpreter: `.venv/Scripts/python -m pytest ...` (forward slashes work in PowerShell and Git Bash). Always `python -m pytest`, never bare `pytest` (puts `backend/` on `sys.path`).
- Contract C1 is the API, exactly: base `/api`, `Authorization: Bearer <supabase access_token>` on everything except `GET /api/health`; errors `401 {detail}` · `404` · `422`.
- Every query is filtered by the token's `sub`; no endpoint accepts a `user_id`. Unknown or other-user ids → **404** (never 403).
- Server payloads contain **hostnames only**. No page titles, URLs, raw events, resume targets or AI keys are accepted or stored (spec §1.3, D-15). Request models use `extra="forbid"` so stray fields are rejected with 422.
- Settings ranges: `grace_s` 120..900, `quiet_hours` ≤3 items of `{from:"HH:MM", to:"HH:MM"}`. `sites` ≤50 hostnames. Goal `title` ≤200, context `title` ≤120. `lines` splitter: split on newlines, trim, drop empties, ≤20 goals. `GET /daily` range ≤31 days.
- Times: API datetimes are ISO-8601 UTC (`...Z`); `day` is `YYYY-MM-DD` in the **profile's tz** (default `Asia/Kathmandu`).
- `DEBUG` defaults to `False`. `DATABASE_URL` defaults to `sqlite:///./focusguard.db`. No Postgres auto-start, no SQLite fallback, no demo seeding.
- JWKS cache lifespan 600 s; `aud="authenticated"`; algorithm **ES256 only**.
- Rate limit: 60 requests/min per user, in-process, marked with a `ponytail:` comment.
- CORS: `DASHBOARD_ORIGINS` (comma list) + exact `chrome-extension://<EXTENSION_ID>`. No regex. `Retry-After` is exposed so cross-origin clients can honour R9's 429 back-off.

## Review Focus

1. **Supabase JWKS endpoint is briefly unreachable** → clients must not be signed out: the API answers **503**, not 401. *(Task 2: `test_jwks_outage_is_503_not_401`)*
2. **An offline extension replays an older context snapshot after a newer one** → the newer state wins; the stale PUT returns the stored row unchanged. *(Task 5: `test_put_updates_with_newer_snapshot_and_ignores_stale_replay`)*
3. **Extension sends a full URL or a page title by mistake** → 422, nothing stored. *(Task 5: `test_put_validation` cases `https://…/document/d/abc`, `page_title`)*
4. **Supabase admin delete fails after app rows are deleted** → 502 with a retry message; a retry succeeds and nothing is left behind. If the user leaves instead of retrying, their next request (which gets 401 from the tombstone) finishes the Supabase deletion. *(Task 7: `test_delete_remote_failure_is_502_after_data_is_gone`, `test_request_after_failed_delete_finishes_auth_removal`)*
5. **A context left unended (extension uninstalled) shows up on every later day** → `GET /contexts?day=` uses `coalesce(ended_at, last_active_at)` so it appears only on days it was active. *(Task 5: `test_day_filter_uses_local_day_bounds`, case `abandoned-last-week`)* For `?active=1`, R6's 30-min rule hides it. *(Task 5: `test_active_hides_stale_context`)*
6. **The extension keeps syncing with a still-valid token after the account is deleted from the dashboard** → 401, no rows re-created (`deleted_users` tombstone). *(Task 7: `test_token_used_after_delete_cannot_recreate_data`)*

```python
from sqlalchemy.orm import DeclarativeBase, sessionmaker

from app.config import get_settings


def db_url(url: str) -> str:
    # Supabase hands out postgresql:// URLs; route them to the installed psycopg (v3) driver.
    if url.startswith("postgresql://"):
        return "postgresql+psycopg://" + url[len("postgresql://") :]

engine = create_engine(
    _url,
    echo=get_settings().debug,
    pool_pre_ping=True,
    connect_args={"check_same_thread": False} if _url.startswith("sqlite") else {},

SessionLocal = sessionmaker(bind=engine, autoflush=False, expire_on_commit=False)


class Base(DeclarativeBase):
    pass

    with SessionLocal() as db:
        yield db
```

```python
from datetime import date, datetime, time, timedelta, timezone
from zoneinfo import ZoneInfo


def utcnow() -> datetime:
    return datetime.now(timezone.utc)


def local_today(tz: str) -> date:
    return utcnow().astimezone(ZoneInfo(tz)).date()


def day_bounds(day: date, tz: str) -> tuple[datetime, datetime]:
    """[start, end) of a local calendar day, as UTC datetimes."""
    zone = ZoneInfo(tz)
    start = datetime.combine(day, time.min, tzinfo=zone)
    end = datetime.combine(day + timedelta(days=1), time.min, tzinfo=zone)
    return start.astimezone(timezone.utc), end.astimezone(timezone.utc)
```

```python
# jsonb on Postgres, JSON text on SQLite (tests/dev). Used for settings and for sites (portable text[]).
JSONType = JSON().with_variant(JSONB(), "postgresql")


class UTCDateTime(TypeDecorator):
    """Stores UTC; always returns an aware UTC datetime (SQLite would otherwise drop tzinfo)."""

    impl = DateTime(timezone=True)
    cache_ok = True

    def process_bind_param(self, value, dialect):
        if value is None:
            return None
        if value.tzinfo is None:
            value = value.replace(tzinfo=timezone.utc)
        return value.astimezone(timezone.utc)

    def process_result_value(self, value, dialect):
        if value is None:
            return None
        if value.tzinfo is None:
            return value.replace(tzinfo=timezone.utc)
        return value.astimezone(timezone.utc)


class Profile(Base):
    __tablename__ = "profiles"

    user_id: Mapped[uuid.UUID] = mapped_column(Uuid, primary_key=True)
    tz: Mapped[str] = mapped_column(String(64), default="Asia/Kathmandu", server_default="Asia/Kathmandu")
```

```python
import time
import uuid
from functools import lru_cache

import jwt
from fastapi import Depends, HTTPException
from fastapi.security import HTTPAuthorizationCredentials, HTTPBearer
from jwt.exceptions import PyJWKClientConnectionError, PyJWTError
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Session

from app.config import get_settings
from app.database import get_db
from app.models import DeletedUser, Profile

RATE_LIMIT_PER_MIN = 60

_bearer = HTTPBearer(auto_error=False)  # auto_error would answer 403; the contract says 401
_hits: dict[uuid.UUID, tuple[int, int]] = {}  # user_id -> (minute window, requests in it)


@lru_cache
def jwks_client() -> jwt.PyJWKClient:
    # Supabase edge-caches its JWKS for 10 min; caching longer than ~20 min risks missing a key rotation.
    # ponytail: an unknown `kid` makes PyJWKClient refetch the JWKS before any rate limit applies, so junk
    # tokens can each cost one outbound fetch (bounded by timeout=5). Throttle unknown-kid refreshes if abused.
    return jwt.PyJWKClient(get_settings().supabase_jwks_url, lifespan=600, timeout=5)


def _unauthorized() -> HTTPException:
    return HTTPException(401, "Invalid or expired token", headers={"WWW-Authenticate": "Bearer"})


def verify_token(token: str) -> uuid.UUID:
    """Supabase access token -> user id. 401 on anything wrong, 503 if the JWKS can't be fetched."""
    s = get_settings()
    try:
        key = jwks_client().get_signing_key_from_jwt(token).key
        claims = jwt.decode(
            token,
            key,
            algorithms=["ES256"],
            audience=s.supabase_audience,
            issuer=s.supabase_issuer,
            options={"require": ["exp", "sub", "aud", "iss"]},
        )
        return uuid.UUID(claims["sub"])
    except PyJWKClientConnectionError:
        # Not the user's fault: a 401 here would sign every client out during a Supabase blip.
        raise HTTPException(503, "Auth keys unavailable, retry shortly") from None
    except (PyJWTError, ValueError):
        raise _unauthorized() from None


def _minute() -> int:
    return int(time.monotonic() // 60)


def _rate_limit(user_id: uuid.UUID) -> None:
    # ponytail: per-process fixed one-minute window, unlocked dict; correct only while Cloud Run
    # max-instances=1. Move to a Postgres/Redis counter if we ever scale out.
    minute = _minute()
    window, count = _hits.get(user_id, (minute, 0))
    if window != minute:
        count = 0
    if count >= RATE_LIMIT_PER_MIN:
        raise HTTPException(429, "Too many requests", headers={"Retry-After": "60"})
    _hits[user_id] = (minute, count + 1)


def current_user_id(cred: HTTPAuthorizationCredentials | None = Depends(_bearer)) -> uuid.UUID:
    if cred is None:
        raise _unauthorized()
    user_id = verify_token(cred.credentials)
    _rate_limit(user_id)
    return user_id


def current_profile(user_id: uuid.UUID = Depends(current_user_id), db: Session = Depends(get_db)) -> Profile:
    """The caller's profile, created on their first authenticated request (never after DELETE /me)."""
    profile = db.get(Profile, user_id)
    if profile is None:
        # A deleted account's access token stays valid until `exp`; it must not re-create rows
        # under a `sub` nobody can sign in as again (so nobody could export or delete them).
        if db.get(DeletedUser, user_id) is not None:
            raise _unauthorized()
        db.add(Profile(user_id=user_id, settings={}))
        try:
            db.commit()
        except IntegrityError:  # a concurrent first request created it
            db.rollback()
        profile = db.get(Profile, user_id)
    return profile
```

```python
# ---------- goals ----------

Category = Literal["work", "learning", "personal"]
Title200 = Annotated[str, StringConstraints(strip_whitespace=True, min_length=1, max_length=200)]


def split_lines(text: str) -> list[str]:
    """'a\\n\\n  b, c \\r\\n' -> ['a', 'b, c']: one goal per line, trimmed, empties dropped.

    Splits on \\r\\n, \\r and \\n only (R3, same as the dashboard's /\\r\\n|\\r|\\n/); str.splitlines()
    would also split on \\v, \\f, U+2028, ... and create more goals than the preview showed."""
    return [s for s in (line.strip() for line in re.split(r"\r\n|\r|\n", text)) if s]


class GoalCreate(Strict):
    title: Title200 | None = None
    lines: str | None = Field(default=None, max_length=5000)
    category: Category = "work"
    day: date | None = None

    @model_validator(mode="after")
    def _one_source(self):
        if (self.title is None) == (self.lines is None):
            raise ValueError("send exactly one of title or lines")
        titles = self.titles()
        if not titles:
            raise ValueError("lines contains no goals")
        if len(titles) > 20:
            raise ValueError("at most 20 goals at once")
        if any(len(t) > 200 for t in titles):
            raise ValueError("each goal is at most 200 characters")
        return self

    def titles(self) -> list[str]:
        return [self.title] if self.title is not None else split_lines(self.lines)


class GoalPatch(Strict):
    title: Title200 | None = None
    status: Literal["open", "done"] | None = None
    sort: int | None = Field(default=None, ge=0, le=1_000_000)
    category: Category | None = None


class GoalOut(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    id: uuid.UUID
    day: date
    title: str
    category: Category
    status: Literal["open", "done"]
    sort: int
    created_at: datetime
    done_at: datetime | None
```

```python
import uuid
from datetime import date

from fastapi import APIRouter, Depends, HTTPException, Response
from sqlalchemy import func, select
from sqlalchemy.orm import Session

from app.auth import current_profile
from app.database import get_db
from app.days import local_today, utcnow
from app.models import Goal, Profile
from app.schemas import GoalCreate, GoalOut, GoalPatch

router = APIRouter(prefix="/goals", tags=["goals"])


def _own_goal(db: Session, user_id: uuid.UUID, goal_id: str) -> Goal:
    # goal_id is a plain str so a malformed id is a 404 like any other unknown id, not a 422.
    try:
        gid = uuid.UUID(goal_id)
    except ValueError:
        raise HTTPException(404, "Goal not found") from None
    goal = db.scalar(select(Goal).where(Goal.id == gid, Goal.user_id == user_id))
    if goal is None:
        raise HTTPException(404, "Goal not found")
    return goal


@router.get("", response_model=list[GoalOut])
def list_goals(day: date | None = None, profile: Profile = Depends(current_profile), db: Session = Depends(get_db)):
    day = day or local_today(profile.tz)
    query = select(Goal).where(Goal.user_id == profile.user_id, Goal.day == day).order_by(Goal.sort, Goal.created_at)
    return db.scalars(query).all()


@router.post("", response_model=list[GoalOut], status_code=201)
def create_goals(body: GoalCreate, profile: Profile = Depends(current_profile), db: Session = Depends(get_db)):
    day = body.day or local_today(profile.tz)
    top = db.scalar(select(func.max(Goal.sort)).where(Goal.user_id == profile.user_id, Goal.day == day))
    first = 0 if top is None else top + 1
    goals = [
        Goal(user_id=profile.user_id, day=day, title=title, category=body.category, status="open", sort=first + i)
        for i, title in enumerate(body.titles())
    ]
    db.add_all(goals)
    db.commit()
    return goals


@router.patch("/{goal_id}", response_model=GoalOut)
def patch_goal(
    goal_id: str, body: GoalPatch, profile: Profile = Depends(current_profile), db: Session = Depends(get_db)
):
    goal = _own_goal(db, profile.user_id, goal_id)
    changes = body.model_dump(exclude_none=True)
    if changes.get("status") == "done" and goal.status != "done":
        goal.done_at = utcnow()
    if changes.get("status") == "open":
        goal.done_at = None
    for field, value in changes.items():
        setattr(goal, field, value)
    db.commit()
    return goal


@router.delete("/{goal_id}", status_code=204)
def delete_goal(goal_id: str, profile: Profile = Depends(current_profile), db: Session = Depends(get_db)):
    db.delete(_own_goal(db, profile.user_id, goal_id))
    db.commit()
    return Response(status_code=204)
```

```python
from sqlalchemy.orm import Session

router = APIRouter(prefix="/contexts", tags=["contexts"])


@router.put("/{context_id}", response_model=ContextSnap)
def put_context(
    body: ContextSnap,
    context_id: str = Path(pattern=r"^[A-Za-z0-9_-]{1,64}$"),
    profile: Profile = Depends(current_profile),
    db: Session = Depends(get_db),
):
    if body.id != context_id:
        raise HTTPException(422, "Body id must equal the id in the URL")
    row = db.get(Context, (profile.user_id, context_id))
    if row is not None and row.last_active_at > body.last_active_at:
        return row  # stale replay from an offline queue: keep the newer snapshot
    if row is None:
        row = Context(user_id=profile.user_id, id=context_id)
        db.add(row)
    for field, value in body.model_dump(exclude={"id"}).items():
        setattr(row, field, value)
    db.commit()
    return row


@router.get("", response_model=list[ContextSnap])
def list_contexts(
    day: date | None = None,
    active: bool = False,
    profile: Profile = Depends(current_profile),
    db: Session = Depends(get_db),
):
    query = select(Context).where(Context.user_id == profile.user_id)
    if active:
        latest = db.scalars(
            query.where(Context.ended_at.is_(None)).order_by(Context.last_active_at.desc()).limit(1)
        ).first()
        # R6: a context not heard from in 30 min (extension re-PUTs at least every 10) is not current.
        # days.utcnow via the module, so tests' freeze() applies.
        if latest is None or days.utcnow() - latest.last_active_at > timedelta(minutes=30):
            return []
        return [latest]
    start, end = day_bounds(day or local_today(profile.tz), profile.tz)
    # Overlaps [start, end). An unended context counts until its last activity, so an abandoned
    # one does not show up on every later day.
    overlapping = query.where(
        Context.started_at < end,
        func.coalesce(Context.ended_at, Context.last_active_at) >= start,
    ).order_by(Context.started_at)
    return db.scalars(overlapping).all()
```

```python
from datetime import date

from fastapi import APIRouter, Depends, HTTPException, Query
from sqlalchemy import func, select
from sqlalchemy.orm import Session

from app.auth import current_profile
from app.database import get_db
from app.models import DailyTotal, Profile
from app.schemas import COUNTERS, DailySum, DailyTotals

router = APIRouter(prefix="/daily", tags=["daily"])


@router.put("/{day}", response_model=DailyTotals)
def put_daily(day: date, body: DailyTotals, profile: Profile = Depends(current_profile), db: Session = Depends(get_db)):
    if body.day != day:
        raise HTTPException(422, "Body day must equal the day in the URL")
    row = db.get(DailyTotal, (profile.user_id, day, body.device_id))
    if row is None:
        row = DailyTotal(user_id=profile.user_id, day=day, device_id=body.device_id)
        db.add(row)
    for field in COUNTERS:  # absolute values: last write wins, so retries never double-count
        setattr(row, field, getattr(body, field))
    db.commit()
    return row


@router.get("", response_model=list[DailySum])
def get_daily(
    from_: date = Query(alias="from"),
    to: date = Query(),
    profile: Profile = Depends(current_profile),
    db: Session = Depends(get_db),
):
    if to < from_ or (to - from_).days >= 31:
        raise HTTPException(422, "from must be <= to and the range at most 31 days")
    sums = [func.sum(getattr(DailyTotal, f)).label(f) for f in COUNTERS if f != "longest_detour_s"]
    query = (
        select(DailyTotal.day, *sums, func.max(DailyTotal.longest_detour_s).label("longest_detour_s"))
        .where(DailyTotal.user_id == profile.user_id, DailyTotal.day >= from_, DailyTotal.day <= to)
        .group_by(DailyTotal.day)
        .order_by(DailyTotal.day)
    )
    return [row._asdict() for row in db.execute(query)]
```

```python
        changes = body.settings.model_dump(exclude_none=True, by_alias=True)

def delete_auth_user(user_id: uuid.UUID) -> None:
    """Supabase admin deleteUser. Skipped when no Supabase project is configured (local dev, tests)."""
    s = get_settings()
    if not (s.supabase_url and s.supabase_service_role_key):
        return
    key = s.supabase_service_role_key
    try:
        r = http.delete(
            f"{s.supabase_url.rstrip('/')}/auth/v1/admin/users/{user_id}",
            headers={"apikey": key, "Authorization": f"Bearer {key}"},
        )
    except httpx.HTTPError:
        r = None
    if r is None or (r.status_code >= 400 and r.status_code != 404):  # 404 = already gone, fine
        raise HTTPException(502, "Your data is deleted, but removing the sign-in failed. Please retry.")


@router.delete("", status_code=204)
def delete_me(uid: uuid.UUID = Depends(current_user_id), db: Session = Depends(get_db)):
    # current_user_id, not current_profile: a retry after a 502 must reach here past the tombstone.
    for model in (Goal, Context, DailyTotal, Profile):
        db.execute(delete(model).where(model.user_id == uid))
    if db.get(DeletedUser, uid) is None:  # tombstone: stops a still-valid token re-creating rows
        db.add(DeletedUser(user_id=uid))
    db.commit()
    delete_auth_user(uid)  # after the commit: a failed remote call never leaves app data behind
    return Response(status_code=204)
```

- [ ] **Step 4b: Finish a failed auth deletion from the tombstone branch**

After a 502, the client may reload instead of retrying; its next `GET /me` hits the tombstone 401 and signs out, and the "Delete my account" button is never reachable again. So the tombstone branch retries the Supabase deletion before answering 401. In `backend/app/auth.py`, replace the whole `current_profile` function with:

```python
def current_profile(user_id: uuid.UUID = Depends(current_user_id), db: Session = Depends(get_db)) -> Profile:
    """The caller's profile, created on their first authenticated request (never after DELETE /me)."""
    profile = db.get(Profile, user_id)
    if profile is None:
        # A deleted account's access token stays valid until `exp`; it must not re-create rows
        # under a `sub` nobody can sign in as again (so nobody could export or delete them).
        if db.get(DeletedUser, user_id) is not None:
            from app.routers import me  # lazy: me.py imports app.auth

            # Finish an earlier DELETE /me whose Supabase call hit a 502 (spec §3.3, index R9).
            # Idempotent (404 = already gone); bounded by the 60/min rate limit.
            try:
                me.delete_auth_user(user_id)
            except HTTPException:
                pass
            raise _unauthorized()
        db.add(Profile(user_id=user_id, settings={}))
        try:
            db.commit()
        except IntegrityError:  # a concurrent first request created it
            db.rollback()
        profile = db.get(Profile, user_id)
    return profile
```
