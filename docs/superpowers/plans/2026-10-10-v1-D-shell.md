# FocusGuard v1 · Stream D · Extension Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the hackathon `background.js` with an ES-module service worker that feeds Chrome events through a pure engine (stream A) via a serialized dispatch queue, executes the engine's effects (alarms, nudge card or notification, tab groups, resume, sync), and uploads only context snapshots (hostnames) and absolute daily totals.

**Architecture:** `background.js` only registers listeners and wires modules together. Every module under `extension/shell/` is a factory that takes its dependencies (`chrome`, `fetch`, `step`, `getAccessToken`, `classify`, …) as parameters, so everything runs under `node --test` with the in-memory fake `chrome` from `shell/test/fake-chrome.js` and a stub engine. The flow is: event → `adapters.js` (pure) → `dispatch.js` queue (load `fg_engine` → `step` → **persist** → effects) → `effects.js` core executors + `surfaces.js` (card/notifications) → after-step hooks (`sync.js` accumulator, `hints.js` AI tier hints, heartbeat keeper).

**Tech Stack:** Chrome MV3 (ES-module service worker, `minimum_chrome_version` 120), plain JS with `// @ts-check` + JSDoc, `node:test` + `node:assert/strict` (Node 24), no npm runtime deps, no bundler.

**Spec:** `docs/specs/2026-10-10-v1-core-design.md` (§2, §4.1–4.4, §6, §7) with normative appendices `docs/research/2026-10-10-engine-design-notes.md` (§2 shell rules, §4 tab groups/resume, §5 mapping) and `docs/research/2026-10-10-chrome-platform.md`. Contracts C1–C4, storage keys and ownership: `docs/superpowers/plans/2026-10-10-v1-core-index.md`.

**This is a clean rewrite.** There are no real users yet, so there is **no shadow mode and no state migration** (engine notes §5 "Migration order" steps 4–7 are skipped). The old `background.js`, `content.js` and their message types (`WATCHDOG_*`, `SHOW_INTERVENTION`, `LOG_EVENT`, `CONFIRM_CONTEXT`, …) are deleted, not adapted.

## Review Focus

1. **No host access, or injection refused (chrome://, Chrome Web Store, PDF viewer, tab closed)** → the nudge falls back to a notification with ≤2 buttons; never a crash, never a silent loss. *(Task 9 tests "no host access", "injection throws", "tab gone")*
2. **User double-clicks a card button, or clicks the card and the notification for the same nudge** → exactly one engine command takes effect (cmd `id` = `${interventionId}:${action}`, deduped by the engine's id ring). *(Task 12 test "same action twice → same id")*
3. **Offline or signed out for a day, then back** → totals keep accumulating locally, upload once as absolute values, retries back off, and an `observe` that lands during a slow upload is never lost. *(Task 11 tests "offline a day", "signed out", "observe during upload")*
4. **Chrome delays or clamps an alarm (30 s minimum, laptop sleep) or the browser restarts** → the engine receives the alarm's original due time (name `kind@ms`), so its stale-alarm check works; a browser start (`runtime.onStartup` only) sends `heartbeat startup`, which re-derives every engine alarm; an extension update (`runtime.onInstalled`) never steps the engine and only rebuilds engine alarms from the persisted state, so live tab/group ids survive. `beast:*` and `fg_sync` are never touched. *(Task 4 test "late alarm keeps dueAt", Task 8 tests "restart" and "update (onInstalled)")*
5. **Typing in the card's inputs on a site with keyboard shortcuts (YouTube `k`, space)** → keystrokes inside the card do not reach the page; the card never steals focus when it appears. *(Task 7 tests "keys inside the card stop", "no focus steal")*

```js
// @ts-check
// Central extension config (C4, R11/R28). CONFIG holds the checked-in defaults and is synchronous.
// Dev overrides live in the gitignored extension/config.local.json (copy config.local.example.json);
// background.js copies it into storage.local `fg_config_override` at startup, and getConfig() merges it.
// Service workers forbid dynamic import() and top-level await, hence fetch + storage.

/** @typedef {{API_URL:string, SUPABASE_URL:string, SUPABASE_ANON_KEY:string, DASHBOARD_URL:string}} Config */

/** @type {Readonly<Config>} */
export const CONFIG = Object.freeze({
  API_URL: "http://localhost:8000",
  SUPABASE_URL: "",
  SUPABASE_ANON_KEY: "",
  DASHBOARD_URL: "http://localhost:8081",
});

/**
 * CONFIG merged with fg_config_override. ENGINE = dev-only engine overrides, e.g. {"GRACE_DEFAULT_S": 60}. Never throws.
 * @param {{get:(k:string)=>Promise<Record<string, any>>}|undefined} [storage]
 * @returns {Promise<Config & {ENGINE: Record<string, number>}>}
 */
export async function getConfig(storage = globalThis.chrome?.storage?.local) {
  try {
    const o = storage ? (await storage.get("fg_config_override")).fg_config_override : null;
    return { ...CONFIG, ...(o || {}), ENGINE: o?.ENGINE || {} };
  } catch {
    return { ...CONFIG, ENGINE: {} };
  }
}

/**
 * Copy config.local.json into fg_config_override; a missing file removes the key so stale overrides clear. Never throws.
 * @param {(url:string)=>Promise<{ok:boolean, json:()=>Promise<any>}>} [fetchFn]
 * @param {(path:string)=>string} [getURL]
 * @param {{set:(o:Record<string, any>)=>Promise<void>, remove:(k:string)=>Promise<void>}} [storage]
 */
export async function loadLocalConfigIntoStorage(
  fetchFn = (u) => fetch(u),
  getURL = (p) => globalThis.chrome.runtime.getURL(p),
  storage = globalThis.chrome?.storage?.local,
) {
  try {
    const res = await fetchFn(getURL("config.local.json"));
    if (res.ok) return void (await storage?.set({ fg_config_override: await res.json() }));
  } catch {
    /* no local config */
  }
  try {
    await storage?.remove("fg_config_override");
  } catch {
    /* storage unavailable: defaults stand */
  }
}
```

```js
// @ts-check
/** SPEC §10.3: never shown to users, from templates or AI. */
export const BANNED = ["lazy", "failed", "wasted", "distracted again", "you should have", "disappointing"];

/** @param {string} text */
export function hasBanned(text) {
  const t = String(text).toLowerCase();
  return BANNED.some((w) => t.includes(w));
}

/**
 * Replace {name} placeholders; missing values become "".
 * @param {string} template
 * @param {Record<string, unknown>} vars
 */
export function fill(template, vars) {
  return template.replace(/\{(\w+)\}/g, (_, k) => (vars[k] == null ? "" : String(vars[k])));
}

/**
 * Deterministic pick, so the same intervention always shows the same line.
 * @template T
 * @param {T[]} list
 * @param {string} seed
 * @returns {T}
 */
export function pick(list, seed) {
  let h = 0;
  for (const ch of String(seed)) h = (h * 31 + (ch.codePointAt(0) ?? 0)) | 0;
  return list[Math.abs(h) % list.length];
}
```

```js
// @ts-check
// Pure adapters: Chrome objects → engine inputs. No chrome.* here.
import { isSensitiveHost, sanitizeTitle } from "../privacy.js";
import { normalizeHost } from "../engine/tiers.js"; // R20: A owns host normalization

/** @typedef {{id?:number, url?:string, title?:string, incognito?:boolean, active?:boolean, windowId?:number}} TabLike */
/** @typedef {{type:'landing', tabId:number, host:string|null, title:string, ts:number}} LandingInput */

/** Alarms D schedules for the engine: `${kind}@${atMs}`. */
export const ENGINE_ALARM = /^(grace|escalate|soft_confirm|pause_end|heartbeat)@(\d+)$/;

/** @param {string} host @param {string} suffix */
export function hostMatches(host, suffix) {
  return host === suffix || host.endsWith("." + suffix);
}

/**
 * Raw tab → landing. Blind (host:null, title:'') for incognito, non-web pages,
 * sensitive hosts and the user's extra-sensitive list, so the engine never sees them.
 * @param {TabLike|null|undefined} tab
 * @param {{now:number, extraSensitive?:string[]}} opts
 * @returns {LandingInput}
 */
export function tabToInput(tab, { now, extraSensitive = [] }) {
  /** @type {LandingInput} */
  const blind = { type: "landing", tabId: tab?.id ?? -1, host: null, title: "", ts: now };
  if (!tab || tab.incognito || !tab.url) return blind;
  let url;
  try {
    url = new URL(tab.url);
  } catch {
    return blind;
  }
  if (url.protocol !== "https:" && url.protocol !== "http:") return blind;
  // Normalize BEFORE the privacy checks: "online.chase.com." must not slip past the $-anchored patterns.
  const h = normalizeHost(url.hostname);
  if (!h || isSensitiveHost(h) || extraSensitive.some((s) => hostMatches(h, normalizeHost(String(s))))) return blind;
  return { type: "landing", tabId: tab.id ?? -1, host: h, title: sanitizeTitle(tab.title), ts: now };
}

/** @param {string} kind @param {number} at */
export function alarmName(kind, at) {
  return `${kind}@${at}`;
}

/**
 * chrome.alarms.Alarm → engine input. dueAt comes from the name, not scheduledTime,
 * because Chrome clamps short alarms to 30 s and fires late after sleep.
 * @param {{name:string, scheduledTime:number}} alarm
 */
export function alarmToInput(alarm) {
  if (alarm.name === "heartbeat") return { type: "heartbeat", reason: "tick" };
  const m = ENGINE_ALARM.exec(alarm.name);
  if (!m) return null;
  if (m[1] === "heartbeat") return { type: "heartbeat", reason: "tick" };
  return { type: "alarm", kind: m[1], dueAt: Number(m[2]) };
}

/**
 * Should a tabs.onUpdated event become a landing?
 * @param {{status?:string}} info
 * @param {TabLike} tab
 * @param {{id?:number, focused?:boolean}|null|undefined} win  chrome.windows.getLastFocused()
 */
export function shouldLand(info, tab, win) {
  return !!tab.active && info.status === "complete" && !!win?.focused && win.id === tab.windowId;
}
```

```js
// @ts-check
// Settings (C4). Server settings come from GET /me (cached in fg_settings_cache);
// extension-only settings stay in storage.local (D-15).

const HOUR_MS = 3_600_000;
const DEFAULT_GRACE_S = 300;

/** @typedef {{grace_s:number, quiet_hours:{from:string,to:string}[], aiMode:string, beastUntil:number|null, relatedRules:any[], extraSensitive:string[], tz:string}} Settings */

/**
 * @param {{chrome?:any, fetch?:(url:string, init?:any)=>Promise<any>, getAccessToken?:(o?:{force?:boolean})=>Promise<string|null>, signOut?:()=>Promise<void>, apiUrl?:()=>string, now?:()=>number}} [deps]
 */
export function createSettings(deps = {}) {
  const c = () => deps.chrome ?? globalThis.chrome;
  const now = deps.now ?? Date.now;
  const fetchFn = deps.fetch ?? ((url, init) => fetch(url, init));

  /** @returns {Promise<Settings>} */
  async function getSettings() {
    const got = await c().storage.local.get(["fg_settings_cache", "fg_ai", "fg_beast", "fg_rules", "fg_extra_sensitive"]);
    const profile = got.fg_settings_cache?.profile;
    const s = profile?.settings ?? {};
    return {
      grace_s: s.grace_s ?? DEFAULT_GRACE_S,
      quiet_hours: s.quiet_hours ?? [],
      aiMode: got.fg_ai?.mode ?? "off",
      beastUntil: got.fg_beast?.until ?? null,
      relatedRules: got.fg_rules ?? [],
      extraSensitive: got.fg_extra_sensitive ?? [],
      tz: profile?.tz ?? Intl.DateTimeFormat().resolvedOptions().timeZone,
    };
  }

  /**
   * GET /me into fg_settings_cache when older than maxAgeMs, or when forced. Never throws.
   * @param {{force?:boolean, maxAgeMs?:number}} [opts]
   * @returns {Promise<boolean>} true when the cache was refreshed
   */
  async function refreshSettings({ force = false, maxAgeMs = HOUR_MS } = {}) {
    try {
      const { fg_settings_cache } = await c().storage.local.get("fg_settings_cache");
      if (!force && fg_settings_cache && now() - fg_settings_cache.at < maxAgeMs) return false;
      const { getAccessToken, apiUrl } = deps;
      if (!getAccessToken || !apiUrl) return false;
      const token = await getAccessToken();
      if (!token) return false;
      const get = (/** @type {string} */ tok) => fetchFn(`${apiUrl()}/api/me`, { headers: { Authorization: `Bearer ${tok}` } });
      let res = await get(token);
      if (res.status === 401) {
        // spec §6: refresh once, then signed out. The popup shows it on its next get_view (isSignedIn reads fg_auth).
        const fresh = await getAccessToken({ force: true });
        if (!fresh) return false; // the refresh itself failed (offline, GoTrue 429/5xx): not a sign-out
        res = await get(fresh);
        if (res.status === 401) {
          await deps.signOut?.();
          return false;
        }
      }
      if (!res.ok) return false;
      const profile = await res.json();
      const prevUser = fg_settings_cache?.profile?.user_id;
      if (prevUser && prevUser !== profile.user_id) await purgePreviousUser();
      await c().storage.local.set({ fg_settings_cache: { at: now(), profile } });
      return true;
    } catch {
      return false;
    }
  }

  /** Another account signed in on this browser profile: drop what the previous one left locally (spec §1 goal 5). */
  async function purgePreviousUser() {
    const all = await c().storage.local.get(null);
    const keys = Object.keys(all).filter((k) => k.startsWith("fg_accum:") || k.startsWith("fg_resume:"));
    // No cmd:'end': it would emit a session_end + snapshot that then uploads under the new account.
    // ponytail: removing fg_engine races a step that is mid-flight in the dispatch queue; account switches are rare
    await c().storage.local.remove([...keys, "fg_rules", "fg_engine"]);
  }

  /** @returns {Promise<string>} */
  async function getDeviceId() {
    const { fg_device_id } = await c().storage.local.get("fg_device_id");
    if (fg_device_id) return fg_device_id;
    const id = crypto.randomUUID(); // ponytail: two first-ever concurrent calls could race; onInstalled calls it first
    await c().storage.local.set({ fg_device_id: id });
    return id;
  }

  return { getSettings, refreshSettings, getDeviceId };
}

/** C4: cache-only read (no network). background.js owns refreshSettings. */
export const getSettings = createSettings().getSettings;
```

```js
// @ts-check
// Single promise queue: load fg_engine (storage.local, R33) → step → persist → run effects (engine notes §2).
// A worker killed mid-effects loses at most those effects; the startup heartbeat re-derives alarms.

/** @typedef {{prev:any, state:any, now:number}} StepCtx */

/**
 * Engine cfg for one step. Merge order: engine DEFAULTS < user settings < dev overrides (fg_config_override.ENGINE).
 * @param {Record<string, any>} defaults
 * @param {{grace_s?:number, quiet_hours?:any[], beastUntil?:number|null, tz?:string}} settings
 * @param {{seed?:any, cache?:Record<string, any>, overrides?:Record<string, any>}} [opts]
 */
export function buildCfg(defaults, settings, { seed = null, cache = {}, overrides = {} } = {}) {
  return {
    ...defaults,
    GRACE_DEFAULT_S: settings.grace_s ?? defaults.GRACE_DEFAULT_S,
    tz: settings.tz,
    quietHours: settings.quiet_hours ?? [],
    beastUntil: settings.beastUntil ?? null,
    tables: { seed, cache }, // R21: cache = fg_tier_cache. Related rules are per-context (ctx.relatedHosts, R34), not cfg.
    ...overrides,
  };
}

/**
 * @param {{
 *   step:(prev:any, input:any, now:number, cfg:any)=>{state:any, effects:any[]},
 *   initialState:(now:number)=>any,
 *   chrome:any,
 *   getCfg:()=>Promise<any>,
 *   runEffects:(effects:any[], ctx:StepCtx)=>Promise<void>,
 *   now?:()=>number,
 *   log?:(...a:any[])=>void,
 * }} deps
 */
export function createDispatch({ step, initialState, chrome, getCfg, runEffects, now = Date.now, log = console.error }) {
  /** @type {Promise<any>} */
  let tail = Promise.resolve();

  /** @param {number} t */
  async function loadState(t) {
    const { fg_engine } = await chrome.storage.local.get("fg_engine"); // R33: survives a browser restart
    return fg_engine ?? initialState(t);
  }

  /** @param {any} input */
  async function run(input) {
    const { fg_consent } = await chrome.storage.local.get("fg_consent");
    if (!fg_consent) return null; // nothing is observed before the user clicks Start (spec §4.3)
    const t = now();
    const prev = await loadState(t);
    let result;
    try {
      result = step(prev, input, t, await getCfg());
    } catch (e) {
      log("engine step threw; state unchanged", input?.type, e);
      return null;
    }
    await chrome.storage.local.set({ fg_engine: result.state }); // persist BEFORE effects
    await runEffects(result.effects, { prev, state: result.state, now: t });
    return result;
  }

  /**
   * Serialized: each input sees the state persisted by the previous one. Never rejects.
   * @param {any} input
   * @returns {Promise<{state:any, effects:any[]}|null>}
   */
  function dispatch(input) {
    const p = tail.then(() => run(input)).catch((e) => {
      log("dispatch failed", input?.type, e);
      return null;
    });
    tail = p;
    return p;
  }

  /** Latest persisted state (no consent needed; used by get_view). Must not be awaited from inside an effect. */
  async function getState() {
    await tail;
    return loadState(now());
  }

  return { dispatch, getState };
}
```

```js
// @ts-check
// Pure: engine effect → plain JSON for renderCard (executeScript args must be serializable).
import { fill, pick } from "../copy/copy.js";

/** "+5 min" on the card and the notification. */
export const EXTEND_S = 300;
const MASCOT = "🦉";

/** @param {Record<string,string>} ui @param {Record<string, unknown>} vars */
const fillAll = (ui, vars) => Object.fromEntries(Object.entries(ui).map(([k, v]) => [k, fill(v, vars)]));

/**
 * @param {{level:1|2, interventionId:string, copyKey:string, vars:{context:string, awayMin:number}}} fx
 * @param {{copy:any, seenLevels:number[], settingsUrl:string}} opts
 */
export function nudgeModel(fx, { copy, seenLevels, settingsUrl }) {
  const vars = { context: fx.vars.context || "your task" };
  /** @type {string[]} */
  const lines = copy[fx.copyKey] ?? copy[`nudge_l${fx.level}`]; // R36 keys: nudge_l1 / nudge_l2
  return {
    kind: /** @type {const} */ ("nudge"),
    level: fx.level,
    interventionId: fx.interventionId,
    label: copy.ui.card_label,
    mascot: fx.level === 2 ? MASCOT : null,
    message: fill(pick(lines, fx.interventionId), vars),
    explainer: seenLevels.includes(fx.level) ? null : fill(copy.explainer[String(fx.level)], vars),
    settingsUrl,
    context: vars.context,
    ui: fillAll(copy.ui, vars),
    extendS: EXTEND_S,
  };
}

/**
 * show_recovery → welcome-back card; the user's own note comes first (spec §4.3, SPEC §11.1).
 * @param {{vars:{context:string, note:string|null, awayMin:number}}} fx
 * @param {{copy:any, sites:string[]}} opts
 */
export function welcomeModel(fx, { copy, sites }) {
  const shown = sites.slice(0, 3);
  const vars = { context: fx.vars.context || "your task", note: fx.vars.note ?? "", sites: shown.join(", ") };
  return {
    kind: /** @type {const} */ ("welcome"),
    label: copy.ui.welcome_title,
    title: copy.ui.welcome_title,
    note: fx.vars.note ? fill(copy.ui.your_note, vars) : null,
    message: fill(pick(copy.welcome_back, vars.context), vars),
    sites: shown.length ? fill(copy.ui.sites, vars) : null,
    ui: fillAll(copy.ui, vars),
  };
}
```

```js
/** @param {any} model  NudgeModel | WelcomeModel from nudge/model.js */
export function renderCard(model) {
  const HOST_ID = "focusguard-nudge-host";
  const old = /** @type {any} */ (document.getElementById(HOST_ID));
  if (old) {
    if (old.__fgClose) old.__fgClose();
    else old.remove();
  }

  /** @param {string} tag @param {Record<string,string>} [attrs] @param {string} [text] */
  const el = (tag, attrs = {}, text = "") => {
    const e = /** @type {any} */ (document.createElement(tag));
    for (const [k, v] of Object.entries(attrs)) e.setAttribute(k, v);
    if (text) e.textContent = text;
    return e;
  };
  /** @param {string} label @param {()=>void} onClick @param {Record<string,string>} [attrs] */
  const button = (label, onClick, attrs = {}) => {
    const b = el("button", { type: "button", ...attrs }, label);
    b.addEventListener("click", onClick);
    return b;
  };

  const host = el("div");
  host.id = HOST_ID;
  const root = host.attachShadow({ mode: "closed" });
  const style = el("style");
  style.textContent = [

  ].join("\n");
  const card = el("div", { class: "card", role: "dialog", "aria-modal": "false", "aria-label": model.label });
  root.append(style, card);

  /** @param {string} action @param {Record<string, unknown>} [extra] */
  const send = (action, extra = {}) => {
    try {
      const p = chrome.runtime.sendMessage({ type: "nudge_action", interventionId: model.interventionId, action, ...extra });
      if (p && p.catch) p.catch(() => {});
    } catch {
      /* extension reloaded: nothing to tell */

  };
  const dismiss = () => (model.kind === "nudge" ? send("dismiss") : close());

    };

      const note = noteInput.value.trim();
      send("break", note ? { note } : {});
    };
    const thisIs = button(`${model.ui.this_is} ▾`, () => show(which.hidden ? which : null), { "aria-expanded": "false" });
    /** @param {any} panel */
    const show = (panel) => {
      for (const p of [which, task, brk]) p.hidden = p !== panel;
      thisIs.setAttribute("aria-expanded", String(panel === which || panel === task));
```

```js
// @ts-check
// Core effect executors: alarms, tab groups, focus/reopen, resume targets, related-site rules.
// Nudge/notification surfaces are passed in as `handlers` (shell/surfaces.js).
import { alarmName, ENGINE_ALARM } from "./adapters.js";

export const MODE_COLOR = { work: "blue", learning: "green", personal: "purple" };
const MAX_RESUME_TABS = 20;
const isWeb = (/** @type {string|undefined} */ url) => /^https?:\/\//.test(url ?? "");

/** @typedef {{prev:any, state:any, now:number}} StepCtx */
/** @typedef {(fx:any, ctx:StepCtx)=>Promise<unknown>|unknown} Handler */

/**
 * @param {{chrome:any, handlers?:Record<string, Handler>, afterStep?:Array<(ctx:StepCtx, effects:any[])=>Promise<void>>, log?:(...a:any[])=>void}} deps
 */
export function createEffects({ chrome, handlers = {}, afterStep = [], log = console.warn }) {
  /** @param {string} kind */
  async function clearKind(kind) {
    for (const a of await chrome.alarms.getAll()) if (a.name.startsWith(`${kind}@`)) await chrome.alarms.clear(a.name);
  }

  /** Drop engine alarms only (never E's beast:* alarms or fg_sync). */
  async function clearEngineAlarms() {
    for (const a of await chrome.alarms.getAll()) if (a.name === "heartbeat" || ENGINE_ALARM.test(a.name)) await chrome.alarms.clear(a.name);
  }

  /**
   * runtime.onInstalled (install / extension update / Chrome update): tab and group ids stay valid, so the engine is
   * NOT stepped (A: `heartbeat startup` only from runtime.onStartup). An update can drop alarms, so rebuild the
   * engine alarms from the persisted state. beast:* and fg_sync are untouched.
   * @param {any} state persisted engine state @param {Record<string, number>} alarms A's `alarmsFor(state)`
   */
  async function rearm(state, alarms) {
    await clearEngineAlarms();
    for (const [kind, at] of Object.entries(alarms)) await chrome.alarms.create(alarmName(kind, at), { when: at });
    if (state?.ctx) await chrome.alarms.create("heartbeat", { periodInMinutes: 1 }); // R22, same as keepHeartbeat
  }

  /** @param {string} contextId */
  async function getResume(contextId) {
    const key = `fg_resume:${contextId}`;
    return (await chrome.storage.local.get(key))[key] ?? null;
  }

  /** @param {number} tabId */
  async function activate(tabId) {
    try {
      const t = await chrome.tabs.update(tabId, { active: true });
      await chrome.windows.update(t.windowId, { focused: true });
      return true;
    } catch {
      return false;
    }
  }

  /** @param {any} fx @param {StepCtx} c */
  async function groupTab(fx, { state }) {
    const ctx = state.ctx?.id === fx.contextId ? state.ctx : null;
    const existing = ctx?.groupId;
    if (existing != null && existing !== -1) {
      try {
        await chrome.tabs.group({ groupId: existing, tabIds: [fx.tabId] });
        return;
      } catch {
        /* group closed, or a saved group Chrome refuses to edit: make a new one */
      }
    }
    const groupId = await chrome.tabs.group({ tabIds: [fx.tabId] });
    await chrome.tabGroups.update(groupId, { title: fx.title, color: MODE_COLOR[/** @type {keyof typeof MODE_COLOR} */ (ctx?.mode)] ?? "blue" });
    // The engine learns groupId from tabs.onUpdated(changeInfo.groupId) → tab_group input.
  }

  /** @param {string} contextId */
  async function reopenGroup(contextId) {
    const r = await getResume(contextId);
    if (!r?.tabs?.length) {
      log("reopen_group: no resume target", contextId);
      return;
    }
    const open = await chrome.tabs.query({});
    /** @type {number[]} */ const ids = [];
    /** @type {number[]} */ const groupable = [];
    let focusId = null;
    for (const t of r.tabs) {
      const hit = open.find((/** @type {any} */ o) => o.url === t.url);
      const id = hit ? hit.id : (await chrome.tabs.create({ url: t.url, active: false })).id;
      ids.push(id);
      if (!hit?.pinned) groupable.push(id); // pinned tabs cannot join groups
      if (t.url === r.lastUrl) focusId = id;
    }
    try {
      const groupId = await chrome.tabs.group({ tabIds: groupable });
      await chrome.tabGroups.update(groupId, { title: r.title, color: r.color });
    } catch (e) {
      log("reopen_group: grouping failed; tabs are open ungrouped", e);
    }
    await activate(focusId ?? ids[0]);
  }

  /** @param {any} fx */
  async function focusTab(fx) {
    if (fx.tabId != null && (await activate(fx.tabId))) return;
    const r = await getResume(fx.contextId);
    if (r?.lastUrl) {
      const match = (await chrome.tabs.query({})).find((/** @type {any} */ t) => t.url === r.lastUrl);
      if (match && (await activate(match.id))) return;
    }
    await reopenGroup(fx.contextId);
  }

  /** @param {any} fx @param {StepCtx} c */
  async function persistResume(fx, { state, now }) {
    const ctx = state.ctx;
    if (!ctx || ctx.id !== fx.contextId) return;
    const hasGroup = ctx.groupId != null && ctx.groupId !== -1;
    const grouped = hasGroup ? await chrome.tabs.query({ groupId: ctx.groupId }).catch(() => []) : [];
    const last = ctx.lastTabId != null ? await chrome.tabs.get(ctx.lastTabId).catch(() => null) : null;
    const list = (grouped.length ? grouped : last ? [last] : []).filter((/** @type {any} */ t) => isWeb(t.url));
    let color = MODE_COLOR[/** @type {keyof typeof MODE_COLOR} */ (ctx.mode)] ?? "blue";
    if (grouped.length) color = (await chrome.tabGroups.get(ctx.groupId).catch(() => null))?.color ?? color;
    // Device-only (spec §1.3): never synced, deleted on drop_resume.
    await chrome.storage.local.set({
      [`fg_resume:${ctx.id}`]: {
        contextId: ctx.id, savedAt: now, windowId: list[0]?.windowId ?? -1, groupId: grouped.length ? ctx.groupId : null,
        title: ctx.title, color, lastTabId: ctx.lastTabId ?? null, lastUrl: isWeb(last?.url) ? last.url : null,
        tabs: list.slice(0, MAX_RESUME_TABS).map((/** @type {any} */ t) => ({ url: t.url, title: t.title ?? "", pinned: !!t.pinned })),
      },
    });
  }

  /** "This is part of {context}" → remember the rule for Settings (fg_rules). Other sync records go to shell/sync.js. */
  /** @param {any} fx @param {StepCtx} c */
  async function rememberRule(fx, { state, now }) {
    if (fx.rec?.kind !== "rule" || !fx.rec.host) return;
    const contextId = fx.rec.contextId ?? state.ctx?.id; // R24: the rule record carries contextId
    if (!contextId) return;
    const { fg_rules = [] } = await chrome.storage.local.get("fg_rules");
    if (fg_rules.some((/** @type {any} */ r) => r.host === fx.rec.host && r.contextId === contextId)) return;
    // R26 shape; the popup deletes by host + contextId.
    await chrome.storage.local.set({ fg_rules: [...fg_rules, { host: fx.rec.host, contextId, contextTitle: state.ctx?.title ?? "", at: now }] });
  }

  /** @param {StepCtx} c */
  async function keepHeartbeat({ state }) {
    const has = await chrome.alarms.get("heartbeat");
    if (state.ctx && !has) await chrome.alarms.create("heartbeat", { periodInMinutes: 1 });
    if (!state.ctx && has) await chrome.alarms.clear("heartbeat");
  }

  /** @type {Record<string, Handler>} */
  const all = {
    schedule_alarm: async (fx) => {
      await clearKind(fx.kind);
      await chrome.alarms.create(alarmName(fx.kind, fx.at), { when: fx.at });
    },
    cancel_alarm: (fx) => clearKind(fx.kind),
    group_tab: groupTab,
    focus_tab: focusTab,
    reopen_group: (fx) => reopenGroup(fx.contextId),
    persist_resume: persistResume,
    drop_resume: (fx) => chrome.storage.local.remove(`fg_resume:${fx.contextId}`),
    sync: rememberRule,
    log: (fx) => {
      if (fx.level === "info") console.info("[engine]", fx.msg, fx.data ?? "");
    },
    ...handlers,
  };

  /**
   * Run effects in order (show_recovery last, so its card lands on the refocused tab),
   * each isolated, then the after-step hooks.
   * @param {any[]} effects @param {StepCtx} ctx
   */
  async function runEffects(effects, ctx) {
    const ordered = [...effects.filter((f) => f.type !== "show_recovery"), ...effects.filter((f) => f.type === "show_recovery")];
    for (const fx of ordered) {
      const h = all[fx.type];
      if (!h) {
        log("unknown effect", fx.type);
        continue;
      }
      try {
        await h(fx, ctx);
      } catch (e) {
        log(`effect ${fx.type} failed`, e);
      }
    }
    for (const hook of [keepHeartbeat, ...afterStep]) {
      try {
        await hook(ctx, effects);
      } catch (e) {
        log("after-step hook failed", e);
      }
    }
  }

  return { runEffects, rearm };
}
```

```js
// @ts-check
// Where the user sees things: in-page card (host access only) → notification fallback; badge.
import { nudgeModel, welcomeModel } from "../nudge/model.js";
import { renderCard, removeCard } from "../nudge/card.js";
import { fill } from "../copy/copy.js";

const ICON = "icons/icon128.png";
/** Notification button index → action. Notifications allow at most 2 buttons. */
export const NUDGE_BUTTONS = ["back", "extend"];
export const PROPOSE_BUTTONS = ["confirm", "cancel"];

/** @typedef {{prev:any, state:any, now:number}} StepCtx */

/** @param {{chrome:any, copy:any, settingsUrl:()=>string, log?:(...a:any[])=>void}} deps */
export function createSurfaces({ chrome, copy, settingsUrl, log = console.warn }) {
  /** Inject the card if we hold host access for the tab's origin. @param {number|null|undefined} tabId @param {any} model */
  async function inject(tabId, model) {
    if (tabId == null) return false;
    const tab = await chrome.tabs.get(tabId).catch(() => null);
    let origin;
    try {
      origin = new URL(tab?.url ?? "").origin;
    } catch {
      return false;
    }
    if (!/^https?:/.test(origin)) return false;
    if (!(await chrome.permissions.contains({ origins: [`${origin}/*`] }))) return false;
    try {
      await chrome.scripting.executeScript({ target: { tabId }, func: renderCard, args: [model] });
      return true;
    } catch (e) {
      log("card injection failed; falling back to a notification", e);
      return false;
    }
  }

  async function hideNudge() {
    const { fg_nudge } = await chrome.storage.session.get("fg_nudge");
    if (!fg_nudge) return;
    await chrome.storage.session.remove("fg_nudge");
    await chrome.notifications.clear(`nudge:${fg_nudge.interventionId}`);
    if (fg_nudge.tabId != null) await chrome.scripting.executeScript({ target: { tabId: fg_nudge.tabId }, func: removeCard }).catch(() => {});
  }

  /** @param {any} fx @param {StepCtx} c */
  async function showNudge(fx, { state }) {
    await hideNudge(); // L2 replaces L1, possibly in another tab
    const { fg_seen_explainer = [] } = await chrome.storage.local.get("fg_seen_explainer");
    const model = nudgeModel(fx, { copy, seenLevels: fg_seen_explainer, settingsUrl: settingsUrl() });
    const tabId = state.current?.tabId ?? null;
    if (await inject(tabId, model)) {
      await chrome.storage.session.set({ fg_nudge: { tabId, interventionId: fx.interventionId } });
    } else {
      await chrome.notifications.create(`nudge:${fx.interventionId}`, {
        type: "basic", iconUrl: ICON, title: copy.notif.title, priority: 1,
        message: [model.message, model.explainer].filter(Boolean).join("\n"),
        buttons: NUDGE_BUTTONS.map((a) => ({ title: copy.notif[a] })),
      });
      await chrome.storage.session.set({ fg_nudge: { tabId: null, interventionId: fx.interventionId } });
    }
    if (!fg_seen_explainer.includes(fx.level)) await chrome.storage.local.set({ fg_seen_explainer: [...fg_seen_explainer, fx.level] });
  }

  /** @param {any} fx @param {StepCtx} c */
  async function showRecovery(fx, { state }) {
    const sites = [...(state.ctx?.resources ?? [])].sort((a, b) => b.lastSeen - a.lastSeen).map((r) => r.host);
    const model = welcomeModel(fx, { copy, sites });
    const [tab] = await chrome.tabs.query({ active: true, lastFocusedWindow: true });
    if (await inject(tab?.id, model)) return;
    await chrome.notifications.create("welcome", {
      type: "basic", iconUrl: ICON, title: model.title, message: [model.note, model.message, model.sites].filter(Boolean).join("\n"),
    });
  }

  /** @param {any} fx */
  async function proposeContext(fx) {
    await chrome.action.setBadgeText({ text: "?" });
    await chrome.notifications.create("propose", {
      type: "basic", iconUrl: ICON, priority: 0,
      title: fill(copy.notif.propose, { title: fx.suggested?.title ?? fx.host }),
      message: copy.notif.propose_body,
      buttons: [{ title: copy.notif.yes }, { title: copy.notif.not_now }],
    });
  }

  /** Clear the proposal badge/notification once the proposal is answered or expires. @param {StepCtx} c */
  async function afterStep({ prev, state }) {
    if (prev?.phase === "detected" && state.phase !== "detected") {
      await chrome.action.setBadgeText({ text: "" });
      await chrome.notifications.clear("propose");
    }
  }

  return {
    handlers: {
      show_nudge: showNudge,
      hide_nudge: hideNudge,
      show_recovery: showRecovery,
      show_progress: () => chrome.action.openPopup().catch(() => {}),
      propose_context: proposeContext,
    },
    afterStep,
  };
}
```

```js
// @ts-check
// Spec §4.4.2: unknown host + AI enabled → ask classify() asynchronously, cache per host|context,
// feed the answer back as a tier_hint input. Never blocks the dispatch queue.

const CACHE_MAX = 500;
/** A null answer (no access yet, bad key/model, no verdict) is retried after this long. */
export const MISS_TTL_MS = 10 * 60_000;

/**
 * @param {{
 *   chrome:any,
 *   classify:(q:{host:string, title:string, contextTitle:string})=>Promise<{tier:string, related:boolean}|null>,
 *   getSettings:()=>Promise<{aiMode:string}>,
 *   dispatch:(input:any)=>Promise<unknown>,
 *   log?:(...a:any[])=>void,
 * }} deps
 */
export function createHints({ chrome, classify, getSettings, dispatch, log = console.warn }) {
  /** @type {Map<string, Promise<void>>} */
  const inflight = new Map();
  /** key → when classify last answered null. ponytail: in memory only (a worker restart retries sooner), grows with distinct misses */
  /** @type {Map<string, number>} */
  const missedAt = new Map();

  /** @param {string} key @param {string} ctxId @param {{host:string, title:string, contextTitle:string}} q @param {number} now */
  async function ask(key, ctxId, q, now) {
    try {
      const r = await classify(q);
      if (!r) return void missedAt.set(key, now);
      const { fg_tier_cache = {} } = await chrome.storage.local.get("fg_tier_cache");
      fg_tier_cache[key] = { tier: r.tier, related: !!r.related };
      const keys = Object.keys(fg_tier_cache);
      for (const k of keys.slice(0, Math.max(0, keys.length - CACHE_MAX))) delete fg_tier_cache[k];
      await chrome.storage.local.set({ fg_tier_cache });
      // C2's tier_hint has no contextId and A stores it for the live context: drop an answer for a context that ended.
      const { fg_engine } = await chrome.storage.local.get("fg_engine");
      if (fg_engine?.ctx?.id === ctxId) await dispatch({ type: "tier_hint", host: q.host, tier: r.tier, related: !!r.related });
    } catch (e) {
      log("classify failed; rules stay in charge", e);
    } finally {
      inflight.delete(key);
    }
  }

  /** After-step hook. @param {{state:any, now:number}} ctx */
  async function afterStep({ state, now }) {
    const cur = state.current;
    const ctx = state.ctx;
    if (!ctx || !cur?.host || cur.tier !== "unknown") return;
    const key = `${cur.host}|${ctx.id}`;
    if (inflight.has(key) || now - (missedAt.get(key) ?? -Infinity) < MISS_TTL_MS) return;
    const { fg_tier_cache = {} } = await chrome.storage.local.get("fg_tier_cache");
    if (key in fg_tier_cache) return;
    if ((await getSettings()).aiMode === "off") return;
    inflight.set(key, ask(key, ctx.id, { host: cur.host, title: cur.title, contextTitle: ctx.title }, now)); // not awaited
  }

  /** Resolves when every in-flight request has settled (tests, shutdown). */
  async function idle() {
    await Promise.all([...inflight.values()]);
  }

  return { afterStep, idle };
}
```

- Consumes: engine `sync` records (fields used: `id`, `kind`, `day` (R32, local `YYYY-MM-DD`); `intervention.suppressed`; `response.response`; `recovery.trigger`, `recovery.awayS`; `focus.seconds`, with `focusS` read as a fallback); state `phase`, `ctx {id, title, mode, confidence, startedAt, resources[{host}]}`; C1 `PUT /contexts/{id}` (`ContextSnap`), `PUT /daily/{day}` (`DailyTotals` with `device_id`); E `getAccessToken({force?})`; Task 5 `getSettings().tz`, `getSettings().extraSensitive`, `getDeviceId()`, `fg_settings_cache.profile.user_id`.
- Produces:
  - `dayKey(ms, tz) → 'YYYY-MM-DD'`
  - `applyRecord(totals, rec) → totals` (pure; `focus` records add their seconds to `focus_s`, R32)
  - `snapshot(ctx, phase, deviceId, now, ended?, extraSensitive?) → ContextSnap` (`sites` keeps only hostnames that pass B's hostname rule and are neither `isSensitiveHost` nor under a user extra-sensitive suffix, so a host collected before the user added it to `fg_extra_sensitive` stops being uploaded; `observe` passes `getSettings().extraSensitive`).   - `createSync({chrome, fetch?, getAccessToken, signOut?, getSettings, getDeviceId, apiUrl, now?, log?})` → `{observe(ctx, effects), flush({force?}), settled()}`. `observe` is an after-step hook (runs inside the dispatch queue, storage only, then fires `flush` without awaiting it when a context snapshot changed). Records are filed under `fg_accum:<rec.day>` (R32; today's key when `day` is missing or empty); context snapshots go to today's accumulator. A snapshot is marked dirty on a state change **or every 10 min while the context exists** (R6), so `last_active_at` never goes stale. `fg_accum:<day>` = `{day, totals, seen, ver, sentVer, sentAt, contexts: {[id]: {snap, sig, at, sentSig}}, retry: {n, at}|null}` where `sentSig` holds the `${sig}@${at}` mark last sent. Each PUT is isolated: a permanent 4xx (400–499 except 401/408/429) is logged and dropped, so one bad snapshot never blocks the daily totals; network errors, a 401 whose forced token refresh yields no token, 408, 429 (honouring `Retry-After`) and 5xx back off with alarm `fg_sync`, 30 s × 2^(n-1), max 1 h. A 401 again on the retry with a fresh token calls `signOut()` once and stops the flush with every accumulator kept and no backoff (spec §6). No upload when the token's `sub` differs from the cached profile's `user_id` (another account; Task 5 purges on refresh).

```js
// @ts-check
// Spec §4.2/§4.4.3: engine sync records → local per-day accumulator → PUT /contexts/{id} (on change and
// every 10 min, R6) and PUT /daily/{day} (≤ every 5 min, on session end, after midnight). Absolute totals: retries are safe.
import { isSensitiveHost } from "../privacy.js";
import { hostMatches } from "./adapters.js";
import { normalizeHost } from "../engine/tiers.js"; // R20: A owns host normalization

const FIVE_MIN_MS = 5 * 60_000;
const CTX_REFRESH_MS = 10 * 60_000; // R6: the backend hides a context whose last_active_at is >30 min old
const BASE_BACKOFF_MS = 30_000;
const MAX_BACKOFF_MS = 3_600_000;
const SEEN_MAX = 200;
const ZERO = { focus_s: 0, nudges: 0, self_returns: 0, recoveries: 0, snoozes: 0, breaks: 0, longest_detour_s: 0 };
const STATES = new Set(["detected", "active", "grace", "intervened_l1", "escalated_l2", "on_break"]);
// B's Hostname rule: anything else (IPv6 literal, underscore, label >63) would 422 the whole snapshot.
const HOST_RE = /^(?=.{1,253}$)[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?(\.[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?)*$/;
const iso = (/** @type {number} */ ms) => new Date(ms).toISOString();
/** A 4xx that a retry cannot fix. */
const isPermanent = (/** @type {number} */ st) => st >= 400 && st < 500 && st !== 401 && st !== 408 && st !== 429;

/** @typedef {typeof ZERO} Totals */
/** @typedef {{snap:any, sig:string, at:number, sentSig:string|null}} CtxEntry */
/** @typedef {{day:string, totals:Totals, seen:string[], ver:number, sentVer:number, sentAt:number, contexts:Record<string,CtxEntry>, retry:{n:number, at:number}|null}} Accum */

/** "Sent" mark: includes `at`, so a 10-min refresh with an unchanged sig still counts as unsent. @param {CtxEntry} c */
const mark = (c) => `${c.sig}@${c.at}`;

/** JWT `sub` (no verification: only used to avoid uploading under the wrong account). @param {string} token */
function jwtSub(token) {
  try {
    return JSON.parse(atob(token.split(".")[1].replace(/-/g, "+").replace(/_/g, "/"))).sub ?? null;
  } catch {
    return null;
  }
}

/** @param {number} ms @param {string} tz */
export function dayKey(ms, tz) {
  try {
    return new Intl.DateTimeFormat("en-CA", { timeZone: tz, year: "numeric", month: "2-digit", day: "2-digit" }).format(ms);
  } catch {
    return iso(ms).slice(0, 10); // invalid tz: UTC rather than crash
  }
}

/** Pure. @param {Totals} t @param {any} rec */
export function applyRecord(t, rec) {
  switch (rec.kind) {
    case "intervention":
      if (!rec.suppressed) t.nudges++;
      break;
    case "response":
      if (rec.response === "extend") t.snoozes++;
      break;
    case "recovery":
      if (rec.trigger === "self_returned") t.self_returns++;
      else t.recoveries++;
      t.longest_detour_s = Math.max(t.longest_detour_s, Math.round(rec.awayS ?? 0));
      break;
    case "break":
      t.breaks++;
      break;
    case "focus": // R32: the engine owns focus time (`seconds`; an older `focusS` field is read as a fallback)
      t.focus_s += Number(rec.seconds ?? rec.focusS ?? 0);
      break;
  }
  return t;
}

/**
 * C1 ContextSnap: hostnames only, never page titles or URLs.
 * @param {any} ctx @param {string} phase @param {string} deviceId @param {number} now @param {boolean} [ended]
 * @param {string[]} [extraSensitive] the user's fg_extra_sensitive list, applied here too: a host collected before the user added it must stop being uploaded
 */
export function snapshot(ctx, phase, deviceId, now, ended = false, extraSensitive = []) {
  return {
    id: ctx.id, device_id: deviceId, title: String(ctx.title).slice(0, 120), mode: ctx.mode,
    state: ended ? "ended" : STATES.has(phase) ? phase : "active",
    confidence: ctx.confidence, started_at: iso(ctx.startedAt), ended_at: ended ? iso(now) : null, last_active_at: iso(now),
    // Hosts B would reject, or that are (now) sensitive, are left out of the upload only; they stay in local state.
    sites: [...new Set((ctx.resources ?? []).map((/** @type {any} */ r) => r.host)
      .filter((/** @type {unknown} */ h) => typeof h === "string" && HOST_RE.test(h))
      .filter((/** @type {string} */ h) => !isSensitiveHost(h) && !extraSensitive.some((s) => hostMatches(h, normalizeHost(String(s))))))].slice(0, 50),
  };
}

/** @param {string} day @returns {Accum} */
const fresh = (day) => ({ day, totals: { ...ZERO }, seen: [], ver: 0, sentVer: 0, sentAt: 0, contexts: {}, retry: null });

/**
 * @param {{chrome:any, fetch?:(url:string, init?:any)=>Promise<any>, getAccessToken:(o?:{force?:boolean})=>Promise<string|null>, signOut?:()=>Promise<void>,
 *   getSettings:()=>Promise<{tz:string, extraSensitive?:string[]}>, getDeviceId:()=>Promise<string>, apiUrl:()=>string, now?:()=>number, log?:(...a:any[])=>void}} deps
 */
export function createSync({ chrome, fetch: fetchFn = (url, init) => fetch(url, init), getAccessToken, signOut = async () => {}, getSettings, getDeviceId, apiUrl, now = Date.now, log = console.warn }) {
  /** @type {Promise<unknown>} */
  let lock = Promise.resolve();
  /** Serialize read-modify-write of fg_accum:* (observe runs in the dispatch queue, flush outside it). @template T @param {()=>Promise<T>} fn @returns {Promise<T>} */
  function locked(fn) {
    const p = lock.then(fn);
    lock = p.catch(() => {});
    return p;
  }
  /** @param {string} key @returns {Promise<Accum|null>} */
  const read = async (key) => (await chrome.storage.local.get(key))[key] ?? null;

  /** After-step hook. @param {{prev:any, state:any, now:number}} ctx @param {any[]} [effects] */
  async function observe({ prev, state, now: t }, effects = []) {
    const recs = effects.filter((f) => f.type === "sync").map((f) => f.rec).filter((r) => r?.id);
    const ended = !!prev?.ctx && prev.ctx.id !== state.ctx?.id;
    const st = await getSettings();
    const today = dayKey(t, st.tz);
    const xs = st.extraSensitive ?? [];
    const did = await getDeviceId();
    // R32: every record lands on its own local day (the engine's rollover records carry the old day).
    /** @type {Map<string, any[]>} */
    const byDay = new Map([[today, []]]);
    for (const rec of recs) {
      const d = rec.day || today; // `||`: the engine's day key starts as ''
      if (!byDay.has(d)) byDay.set(d, []);
      byDay.get(d)?.push(rec);
    }
    const snaps = [];
    // A removed host changes `sig`, so the next heartbeat observe (≤60 s, R22) PUTs a cleaned snapshot over the server copy.
    if (ended) snaps.push(snapshot(prev.ctx, prev.phase, did, t, true, xs));
    if (state.ctx) snaps.push(snapshot(state.ctx, state.phase, did, t, false, xs));
    const ctxDirty = await locked(async () => {
      let dirty = false;
      for (const [day, rs] of byDay) {
        const key = `fg_accum:${day}`;
        const a = (await read(key)) ?? fresh(day);
        let changed = false;
        for (const rec of rs) {
          if (a.seen.includes(rec.id)) continue;
          a.seen = [...a.seen, rec.id].slice(-SEEN_MAX);
          applyRecord(a.totals, rec);
          changed = true;
        }
        if (changed) a.ver++;
        let snapsChanged = false;
        if (day === today) {
          for (const snap of snaps) {
            const sig = JSON.stringify({ ...snap, last_active_at: null });
            const c = a.contexts[snap.id];
            if (c?.sig === sig && t - c.at < CTX_REFRESH_MS) continue;
            // New state, or R6 refresh: store the fresh snap (current last_active_at); the new `at` makes it unsent.
            a.contexts[snap.id] = { snap, sig, at: t, sentSig: c?.sentSig ?? null };
            snapsChanged = true;
          }
        }
        if (changed || snapsChanged) await chrome.storage.local.set({ [key]: a });
        dirty = dirty || snapsChanged;
      }
      return dirty;
    });
    if (ctxDirty) void flush({ force: ended });
  }

  /** @param {{force?:boolean}} opts */
  async function doFlush({ force = false }) {
    let token = await getAccessToken().catch(() => null);
    if (!token) return; // signed out: keep accumulating; sign-in sends settings_changed → flush
    // Per-user isolation (spec §1 goal 5): never upload what another account accumulated on this profile.
    const { fg_settings_cache } = await chrome.storage.local.get("fg_settings_cache");
    const uid = fg_settings_cache?.profile?.user_id;
    const sub = jwtSub(token);
    if (sub && uid && sub !== uid) return void log("sync paused: the token belongs to another account until settings refresh");
    const t = now();
    const today = dayKey(t, (await getSettings()).tz);
    const did = await getDeviceId();
    /** Set when the server rejected a freshly refreshed token: stop this flush, keep every accumulator. */
    let signedOut = false;

    /** One PUT; on 401 force-refresh the token once and retry; still 401 → sign out (spec §6). Network errors throw. @param {string} path @param {unknown} body */
    async function put(path, body) {
      const send = (/** @type {string} */ tok) => fetchFn(`${apiUrl()}/api${path}`, {
        method: "PUT", headers: { "Content-Type": "application/json", Authorization: `Bearer ${tok}` }, body: JSON.stringify(body),
      });
      let res = await send(/** @type {string} */ (token));
      if (res.status === 401) {
        const freshToken = await getAccessToken({ force: true }).catch(() => null);
        if (freshToken) { // no fresh token (offline, GoTrue 429/5xx) stays a transient 401 and backs off
          token = freshToken;
          res = await send(freshToken);
          if (res.status === 401) {
            signedOut = true;
            await signOut(); // the popup shows signed-out on its next get_view; sign-in → settings_changed → flush
          }
        }
      }
      return res;
    }

    const all = await chrome.storage.local.get(null);
    for (const [key, a] of /** @type {[string, Accum][]} */ (Object.entries(all))) {
      if (signedOut) break;
      if (!key.startsWith("fg_accum:")) continue;
      if (a.retry && a.retry.at > t && !force) continue;
      let transient = false;
      let waitMs = 0;
      /** Each PUT is isolated. @param {string} path @param {unknown} body @returns {Promise<boolean>} true = done (sent, or permanently rejected and dropped) */
      const attempt = async (path, body) => {
        if (signedOut) return false; // not transient: no backoff, so re-auth uploads at once
        try {
          const res = await put(path, body);
          if (res.ok) return true;
          if (signedOut) return false;
          if (isPermanent(res.status)) {
            log(`sync dropped ${path} -> ${res.status}`); // status only, never the body
            return true;
          }
          waitMs = Math.max(waitMs, Number(res.headers?.get?.("Retry-After") ?? 0) * 1000); // R9: 429 Retry-After
        } catch (e) {
          log("sync upload failed; will retry", e);
        }
        transient = true;
        return false;
      };
      /** @type {Record<string, string>} */
      const sentCtx = {};
      for (const [id, c] of Object.entries(a.contexts)) {
        const m = mark(c);
        if (c.sentSig === m) continue;
        if (await attempt(`/contexts/${encodeURIComponent(id)}`, c.snap)) sentCtx[id] = m;
      }
      const dailyDue = a.ver > a.sentVer && (force || a.day !== today || t - a.sentAt >= FIVE_MIN_MS);
      const dailyDone = dailyDue && (await attempt(`/daily/${a.day}`, { day: a.day, device_id: did, ...a.totals, focus_s: Math.round(a.totals.focus_s) }));
      const at = await locked(async () => {
        const cur = await read(key);
        if (!cur) return null;
        // A snapshot refreshed during this flush has a new mark, so it stays unsent.
        for (const [id, m] of Object.entries(sentCtx)) if (cur.contexts[id]) cur.contexts[id].sentSig = m;
        if (dailyDone) {
          cur.sentVer = a.ver;
          cur.sentAt = t;
        }
        if (transient) {
          const n = (cur.retry?.n ?? 0) + 1;
          cur.retry = { n, at: t + Math.max(waitMs, Math.min(MAX_BACKOFF_MS, BASE_BACKOFF_MS * 2 ** (n - 1))) };
        } else cur.retry = null;
        const clean = cur.ver === cur.sentVer && Object.values(cur.contexts).every((c) => c.sentSig === mark(c));
        if (cur.day !== today && clean) await chrome.storage.local.remove(key);
        else await chrome.storage.local.set({ [key]: cur });
        return cur.retry?.at ?? null;
      });
      if (at) await chrome.alarms.create("fg_sync", { when: at });
    }
  }

  /** @type {Promise<void>|null} */
  let running = null;
  /** @type {{force:boolean}|null} */
  let again = null;
  /** Single flight; a request during a flush runs once more afterwards. @param {{force?:boolean}} [opts] */
  function flush(opts = {}) {
    if (running) {
      again = { force: !!(again?.force || opts.force) };
      return running;
    }
    running = (async () => {
      try {
        await doFlush(opts);
        while (again) {
          const o = again;
          again = null;
          await doFlush(o);
        }
      } finally {
        running = null;
      }
    })();
    return running;
  }

  /** Resolves when no flush is running (tests). */
  const settled = async () => {
    while (running) await running;
  };

  return { observe, flush, settled };
}
```

```js
// @ts-check
// C3 runtime messages + notification buttons → engine inputs.
import { EXTEND_S } from "../nudge/model.js";
import { NUDGE_BUTTONS, PROPOSE_BUTTONS } from "./surfaces.js";

const CARD_ACTIONS = new Set(["back", "related", "new_task", "extend", "break", "dismiss"]);

/**
 * Card/notification action → engine cmd. id = `${interventionId}:${action}`, so a double click
 * (or card + notification) is a duplicate the engine ignores (it keeps the last 20 ids).
 * @param {{interventionId?:unknown, action?:unknown, n?:unknown, title?:unknown, note?:unknown}} msg
 */
export function nudgeActionToInput({ interventionId, action, n, title, note }) {
  if (typeof interventionId !== "string" || typeof action !== "string" || !CARD_ACTIONS.has(action)) return null;
  /** @type {{type:'cmd', id:string, cmd:string, n?:number, title?:string, note?:string}} */
  const input = { type: "cmd", id: `${interventionId}:${action}`, cmd: action };
  if (action === "extend") input.n = typeof n === "number" ? n : EXTEND_S;
  if (action === "new_task" && title) input.title = String(title).slice(0, 120);
  if (action === "break" && note) input.note = String(note).slice(0, 280);
  return input;
}

/** @param {string} notificationId @param {number} buttonIndex */
export function notificationToInput(notificationId, buttonIndex) {
  if (notificationId === "propose") {
    const cmd = PROPOSE_BUTTONS[buttonIndex];
    return cmd ? { type: "cmd", cmd } : null;
  }
  const m = /^nudge:(.+)$/.exec(notificationId);
  return m ? nudgeActionToInput({ interventionId: m[1], action: NUDGE_BUTTONS[buttonIndex] }) : null;
}

/**
 * @param {{
 *   dispatch:(input:any)=>Promise<{state:any}|null>, getState:()=>Promise<any>, view:(state:any, now:number)=>any, now:()=>number,
 *   refreshSettings:(o:{force?:boolean, maxAgeMs?:number})=>Promise<boolean>, flush:()=>Promise<void>,
 *   isSignedIn:()=>Promise<boolean>, getDeviceId:()=>Promise<string>,
 *   getRules:()=>Promise<{host:string, contextId:string}[]>, extensionId:string,
 * }} deps
 */
export function createMessageHandler(deps) {
  /** R14: hosts in the live context whose fg_rules entry the popup deleted. */
  async function unrelateDeleted() {
    const state = await deps.getState();
    const ctx = state?.ctx;
    if (!ctx) return;
    const rules = await deps.getRules();
    const keep = new Set(rules.filter((r) => r.contextId === ctx.id).map((r) => r.host));
    for (const host of ctx.relatedHosts ?? []) {
      // No id: A's unrelate is idempotent, and a fixed id would be dropped as duplicate_cmd on a repeat delete.
      if (!keep.has(host)) await deps.dispatch({ type: "cmd", cmd: "unrelate", host });
    }
  }

  /** @param {any} msg @param {{id?:string, url?:string, tab?:unknown}|undefined} sender */
  return async function handle(msg, sender) {
    switch (msg?.type) {
      case "cmd": {
        if (sender?.id !== deps.extensionId || sender.tab) return { ok: false, error: "forbidden" }; // R29: extension pages outside tabs only
        const { type: _t, ...rest } = msg;
        const r = await deps.dispatch({ type: "cmd", ...rest });
        return r ? { ok: true, view: deps.view(r.state, deps.now()) } : { ok: false, error: "no_consent" };
      }
      case "get_view": {
        void deps.refreshSettings({ maxAgeMs: 60_000 }); // spec §3.1: refresh on popup open
        const state = await deps.getState();
        return { view: deps.view(state, deps.now()), signedIn: await deps.isSignedIn(), deviceId: await deps.getDeviceId() };
      }
      case "settings_changed":
        await deps.refreshSettings({ force: true });
        await unrelateDeleted();
        void deps.flush(); // e.g. just signed in: upload what accumulated
        return { ok: true };
      case "nudge_action": {
        const input = nudgeActionToInput(msg);
        if (input) await deps.dispatch(input);
        return { ok: true };
      }
      default:
        return { ok: false, error: "unknown_message" };
    }
  };
}
```

```js
const ready = (async () => {
  await loadLocalConfigIntoStorage(); // config.local.json → fg_config_override (dev only; removed when the file is gone)
  cfg = await getConfig();
  const [seed, copy] = await Promise.all([loadJson("engine/domains.json"), loadJson("copy/en.json")]);
  /** @type {(input:any)=>Promise<any>} */
  let dispatchRef = async () => null;
  const sync = createSync({ chrome, getAccessToken, signOut, getSettings: settings.getSettings, getDeviceId: settings.getDeviceId, apiUrl: () => cfg.API_URL });
  const surfaces = createSurfaces({ chrome, copy, settingsUrl: () => `${cfg.DASHBOARD_URL}/settings` });
  // hints dispatch later, outside the current step; never awaited from inside an effect
  const hints = createHints({ chrome, classify, getSettings: settings.getSettings, dispatch: (i) => dispatchRef(i) });
  const effects = createEffects({ chrome, handlers: surfaces.handlers, afterStep: [surfaces.afterStep, sync.observe, hints.afterStep] });
  const getCfg = async () => {
    const { fg_tier_cache = {} } = await chrome.storage.local.get("fg_tier_cache");
    return buildCfg(DEFAULTS, await settings.getSettings(), { seed, cache: fg_tier_cache, overrides: cfg.ENGINE });
  };
  const { dispatch, getState } = createDispatch({ step, initialState, chrome, getCfg, runEffects: effects.runEffects });
  dispatchRef = dispatch;
  const handle = createMessageHandler({
    dispatch, getState, view, now: Date.now, refreshSettings: settings.refreshSettings, flush: () => sync.flush(),
    isSignedIn, getDeviceId: settings.getDeviceId, extensionId: chrome.runtime.id,
    getRules: async () => (await chrome.storage.local.get("fg_rules")).fg_rules ?? [],
  });
  return { dispatch, getState, effects, sync, handle };

/** @param {any} tab chrome.tabs.Tab or null (no focused window) @param {number} ts event time */
async function land(tab, ts) {
  const r = await ready;
  const { extraSensitive } = await settings.getSettings();
  await r.dispatch(tabToInput(tab, { now: ts, extraSensitive }));
  // R36: commit the pending landing ~0.5 s after the dwell even if no other event comes (the SW stays alive 30 s).
  const dwellS = cfg.ENGINE.DWELL_MIN_S ?? DEFAULTS.DWELL_MIN_S;
  setTimeout(() => void r.dispatch({ type: "heartbeat", reason: "dwell" }), (dwellS + 0.5) * 1000);
}

/** Browser start only (runtime.onStartup): Chrome reassigned tab/group ids; the engine forgets them and re-emits every alarm. */
async function startup() {
  const r = await ready;
  // No await between `ready` and dispatch: a land() still awaiting getSettings() queues behind this step, so the
  // startup step never drops the first real landing as a stale `pending`. No pre-clear: schedule_alarm clears its kind
  // first, and a leftover kind@ms of another kind fires with a dueAt that no longer matches alarmsFor(state), which A ignores.
  await r.dispatch({ type: "heartbeat", reason: "startup" });
}

/** Install / extension update / Chrome update: tab and group ids stay valid, so never step the engine; rebuild its alarms. */
async function rearm() {
  const r = await ready;
  const s = await r.getState();
  await r.effects.rearm(s, alarmsFor(s));
}

  const ts = Date.now();

});

chrome.tabs.onUpdated.addListener((tabId, info, tab) => {
  const ts = Date.now();
  if ("groupId" in info) void send({ type: "tab_group", tabId, groupId: info.groupId }); // drag in/out, our own grouping
  if (!tab.active || info.status !== "complete") return;

});

chrome.tabs.onRemoved.addListener((tabId) => {

    const s = await r.getState();
    if (s?.ctx?.groupTabIds?.includes(tabId)) await r.dispatch({ type: "tab_group", tabId, groupId: -1 });
  }).catch(console.error);
});

chrome.tabGroups.onRemoved.addListener((group) => void send({ type: "tab_group", tabId: null, groupId: group.id, removed: true }));

chrome.windows.onFocusChanged.addListener((windowId) => {
  const ts = Date.now();
  if (windowId === chrome.windows.WINDOW_ID_NONE) return void land(null, ts).catch(console.error); // browser lost focus → blind
  chrome.tabs.query({ active: true, windowId }).then(([t]) => (t ? land(t, ts) : undefined), () => {}).catch(console.error);
});

chrome.idle.onStateChanged.addListener((state) => void send({ type: "idle", state }));

chrome.alarms.onAlarm.addListener((alarm) => {

  if (alarm.name.startsWith("beast:")) return void onBeastAlarm(alarm.name).catch(console.error);

  const input = alarmToInput(alarm);
  if (!input) return; // not an engine alarm
  void ready.then(async (r) => {
    await r.dispatch(input);
    if (input.type === "heartbeat") {
      await settings.refreshSettings(); // hourly TTL inside
      void r.sync.flush();
    }
  }).catch(console.error);
});

chrome.runtime.onMessage.addListener((msg, sender, sendResponse) => {
  ready.then((r) => r.handle(msg, sender)).then(sendResponse, (e) => sendResponse({ ok: false, error: String(e) }));
  return true; // async response
});

chrome.notifications.onButtonClicked.addListener((id, index) => {
  void chrome.notifications.clear(id);
  const input = notificationToInput(id, index);
  if (input) void send(input);
});

chrome.notifications.onClicked.addListener((id) => {
  void chrome.notifications.clear(id);
  // Refused without a focused window, and on Chrome 120–126 outside policy installs (generally available from 127); the badge still shows.
  chrome.action.openPopup().catch(() => {});
});

  void (async () => {
    await settings.getDeviceId();
    if (reason === "install") await chrome.tabs.create({ url: chrome.runtime.getURL("onboarding/onboarding.html") });
    await rearm(); // never `heartbeat startup` here (A Task 12 report): it would drop the live group, lastTabId and any proposal
  })().catch(console.error);
});
```
